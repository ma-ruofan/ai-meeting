# AI Meeting Assistant

面向普通话会议的 AI 会议助理个人项目。

**当前状态：规划阶段，尚未实现可运行应用。**

## 计划功能

- 音频上传、转录与人工校正。
- 结构化会议纪要、决定和行动项提取。
- 原文引用、音频定位与 Markdown 导出。
- 支持会议查询工具的问答 Agent。

## 开发与部署

- Mac 开发：Python、Streamlit、大模型 API。
- Windows 最终部署：faster-whisper、llama.cpp 本地模型服务。
- 存储：SQLite 与本地文件。

具体模型、依赖版本和启动命令将在实现及验证后补充。
