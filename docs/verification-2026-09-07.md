## 真实 ASR 冒烟测试

使用 macOS 系统语音合成的一段虚构普通话内容，音频长 13.16575 秒，16kHz、单声道、16-bit PCM WAV。它不是用户录制会议，不是独立质量评测集。

通过应用的音频导入和 ASR 服务运行 `tiny / cpu / int8`，获得 6 个带时间戳片段并存入 SQLite。

| 项目 | 本次记录 |
|---|---:|
| 模型加载阶段（首次可能包含缓存准备） | 12.014 秒 |
| 转录推理 | 1.558 秒 |
| 推理 RTF | 0.1184 |

输出存在繁体字及“首版”识别为“手板”等错误。该结果只证明真实推理和保存链路可执行；不能据此宣称准确率、真实会议速度或 Windows 性能。未计算 CER。

该音频和运行数据库保留在本机忽略目录 `data/verification/`，不提交为真实会议样例。
