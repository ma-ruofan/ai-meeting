## 已知限制与下一轮输入

1. 请提供你和朋友的独立登记录音及留出的测试录音，校准声纹阈值，观察近场、远场、交替发言和未知者拒识。
2. 请在Windows电脑验证环境安装、麦克风、中文系统音色与手机加入。CI文件已推送；首次GitHub检查因账号账单锁定未能启动，不能替代真机结论。
3. 文本模型选定后验证JSON协议、引用语义、工具选择和费用；现在无需提供密钥。
4. 默认base转录模型以跑通轻量CPU链路为目标，尚不能满足中文专业词准确率要求；后续依据真实音频比较模型，不虚构准确率。
5. 浏览器TTS依赖本地中文音色。无音色时给出文字答案，未完成物理扬声器播放与回声实测。
6. 当前单次录音最长30分钟、单主设备、半双工。主录音设备断网不提供离线持续录音；短窗口声纹不等于可靠的多人重叠分离。
7. 本地数据尚未做应用层磁盘加密；原始登记录音不保留，声纹向量随本场档案删除。仅在本人和朋友的授权测试中使用。

## 可复现命令

```bash
.venv/bin/python scripts/check_v2.py
CHROME_PATH='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' npm exec --prefix frontend -- playwright test --config frontend/playwright.config.ts
```

音频浏览器测试默认跳过，需将 `VOICE_SMOKE_FILE` 指向本人的授权测试WAV；该文件通过Chrome虚拟麦克风注入，不读取计算机真实麦克风。

```bash
.venv/bin/python scripts/verify_speech.py 你的录音.wav --wake-audio 唤醒录音.wav
.venv/bin/python scripts/verify_live.py 唤醒录音.wav
```

当前测试产生的合成音频和原始报告位于忽略Git的 `data/verification/`。UI测试的临时会议由测试清理；界面截图保存在 `docs/screenshots/`。

## 私聊与语音问答分离验证

2026-09-08：新增权限、生命周期和升级迁移测试，后端共15项通过。覆盖：私聊仅本人可读；公共REST/WebSocket/导出/纪要没有私聊；私聊ID无法被采纳；同请求键跨成员互不干扰；私聊可引用共享语音和纪要；语音模型消息中没有私聊；结束会议清空数据并取消正在处理的请求；数据库重开后不恢复已删除私聊；旧文字问答移出公共记录及旧采纳项清理。

浏览器验证使用独立主持人和手机成员身份，检查各自私聊不可互见、刷新可恢复进行中的本人私聊、结束后双方清空并禁用输入。合成语音链路验证共享回答生成、私聊引用其来源、导出仅含共享回答、会议结束后语音问答保留。修复了从共享语音页停止录音的入口，手机导航可横向滚动。仍未调用真实文本大模型，未做物理麦克风/扬声器或Windows真机验证。
